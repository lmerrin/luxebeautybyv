LUXE BEAUTY BY V — WEBSITE v12
Packaged October 19, 2026 (Hawaiʻi)

GITHUB PAGES UPLOAD
1. Unzip this package on your computer.
2. Open your GitHub repository. Choose Add file > Upload files.
3. Upload the CONTENTS of the extracted folder, including assets, index.html,
   style.css, app.js and language.js, directly into the repository root.
   Do not upload the ZIP itself or put everything inside an extra folder.
4. Commit message: Add Luxe Beauty by V website v12
5. In Settings > Pages, choose Deploy from a branch, select your branch
   (usually main), choose /(root), and Save.
6. Open the Pages URL GitHub provides when deployment completes.
   On updates, refresh the page; your browser remembers your language choice.

NO BUILD STEP
This is a static HTML/CSS/JavaScript site. Relative paths support GitHub Pages
project URLs. No npm installation, API keys or server configuration required.
The .nojekyll file bypasses Jekyll processing.

INCLUDED
- Latest hero, layout, menu, exact Square service links and gallery.
- EN / Hawaiian flag toggle, English and draft Hawaiian copy.
- Local photographs, logo, original SVG icons and Monstera motif.
- Self-hosted supplied La Lune font; Italiana and DM Sans load from Google Fonts.
- DESIGN.md documenting the revisions and design decisions.

BEFORE PUBLIC LAUNCH
- The preview intentionally has noindex,nofollow and robots.txt Disallow: /.
  Keep these for client review. Remove noindex/nofollow and update robots.txt
  when the final domain and public launch are approved.
- Hawaiian copy still requires fluent-language editorial review.
- Intake/consent forms are placeholders and do not collect submissions.
- Instagram photos in the carousel are local copies, not an automatic feed.
- Square, Instagram, Google Maps and Google Fonts require internet access.
- Confirm final pricing, address, contact details and photo permissions.
- Confirm that the supplied La Lune font license permits production web use.
- Final-domain canonical URL, social-sharing metadata and sitemap remain
  launch tasks. This package does not connect a domain or submit to Google.
- _headers is for hosts that support it (such as Cloudflare Pages).
  GitHub Pages does not apply these custom headers.
